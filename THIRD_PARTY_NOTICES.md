# Animation reference attribution

The local locomotion curves derive from Quaternius **Universal Animation Library Standard v3**, licensed under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). The creator's pack page credits animator Gonzalo Furnier.

- Creator: https://quaternius.com/packs/universalanimationlibrary.html
- Original download: https://quaternius.itch.io/universal-animation-library
- Source archive, hashes, original license, extraction and sampling records: `assets/source/locomotion/` in the source repository.

The derived data mirrors coordinate handedness, retargets rest frames and limb proportions, closes small loop seams, and records support heights. Playback, blending, stride adaptation and foot support are implemented by this package. The original mannequin is included only in source review material, not the runtime package.
